1

In short

Plenty of crypto trackers are a single page hitting a public price API. CoinPulse is the opposite: a real account system, data that follows the user across devices, and a server that sits between the app and the market feed.

The full loop works end-to-end — register, log in, browse live markets, keep a server-side watchlist, open a coin's detail chart, and track holdings with real-time profit/loss — all behind JWT auth, with an Express API caching CoinPaprika data over a SQLite database.

2

Highlights

Engineering

Real authentication

Register and login with JWT tokens and bcrypt-hashed passwords — protected routes on both the API and the router.

Engineering

Cached API layer

The Express server sits between the app and CoinPaprika, caching responses so the frontend stays fast and the rate limits stay unbothered.

Product

Portfolio with live P/L

Holdings are stored server-side and valued against live prices — profit and loss per coin and for the whole portfolio.

Design

Fintech terminal UI

A dark, data-first interface with Chart.js price history — built to feel like a trading terminal, not a marketing site.
